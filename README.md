# 🛍️ ShopEase – E-Commerce Platform

ShopEase is a modern, responsive frontend e-commerce web application built using HTML, CSS, and JavaScript. It provides users with a seamless online shopping experience, featuring product browsing, search, filtering, shopping cart management, wishlist functionality, dark mode, and a complete checkout flow. Product data is fetched dynamically using the Fake Store API, while browser Local Storage is used to persist user data such as the cart, wishlist, and theme preference.

---

## 🚀 Features

* Responsive and modern user interface
* Browse products from the Fake Store API
* Product search functionality
* Category filtering
* Product sorting (Price & Name)
* Shopping cart with quantity management
* Wishlist management
* Local Storage support for persistent data
* Dark mode toggle
* Checkout page with billing form
* Order summary and confirmation
* Toast notifications
* Loading spinner
* Mobile-friendly design

## ⚙️ How to Run the Project

### Method 1 (Recommended)

1. Download or clone the repository.

```bash
git clone https://github.com/yourusername/shopease.git
```

2. Open the project folder.

3. Open the project using **Visual Studio Code**.

4. Install the **Live Server** extension.

5. Right-click on **index.html** and select **Open with Live Server**.

6. The application will launch automatically in your browser.

---

### Method 2

Simply open the **index.html** file in any modern web browser.

> **Note:** Some browsers restrict API requests when opening files directly. Using **Live Server** is recommended for the best experience.
